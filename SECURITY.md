# Security policy

This page covers how to report a vulnerability in Glass Surface and what is
supported. [CONTRIBUTING.md](CONTRIBUTING.md) covers every other contribution.

## Supported versions

| Version | Supported |
| --- | --- |
| The latest release and `main` | Yes |
| Older releases | No, update to the latest release |

## Reporting a vulnerability

Report vulnerabilities through
[GitHub private vulnerability reporting](https://github.com/svidskiy/glass-surface/security/advisories/new).
Don't open a public issue, pull request, or discussion for a security problem.

Include what helps reproduce and assess the issue:

- The package and its version, and the browser.
- Steps to reproduce, or a proof of concept.
- The impact you expect.

You receive an acknowledgment within three business days and a triage decision
within seven business days.

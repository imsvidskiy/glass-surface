# Security policy

This page covers which versions of Glass Surface are supported and how to
report a vulnerability. [CONTRIBUTING.md](CONTRIBUTING.md) covers every other
contribution.

## Supported versions

| Version | Supported |
| --- | --- |
| The latest release and `main` | Yes |
| Older releases | No; update to the latest release |

## Reporting a vulnerability

Report a vulnerability through
[GitHub private vulnerability reporting](https://github.com/imsvidskiy/glass-surface/security/advisories/new).
Don't open a public issue, pull request, or discussion for a security problem.

Include what helps reproduce and assess the issue:

- The package, its version, and the browser.
- Steps to reproduce, or a proof of concept.
- The impact you expect.

You receive an acknowledgment within three business days and a triage decision
within seven business days. A confirmed vulnerability is fixed in a new
release and disclosed in a GitHub security advisory that credits you, unless
you ask otherwise.
